# 对话标题 · ST-ChatTitle

SillyTavern 扩展：隐藏「最近聊天」列表中强制添加的角色名和分隔符，只显示对话名称。安装一次，切换主题后继续生效。

## 手机安装

1. 打开 SillyTavern 顶部「扩展」（拼图或积木图标）。
2. 点击「安装扩展 / Install extension」。
3. 粘贴 `https://github.com/kyoya0307/ST-ChatTitle`，确认安装。
4. 刷新酒馆网页。
5. 回到「最近聊天」，点击对话旁的铅笔按钮，输入想要显示的标题。

若以前粘贴过「最近聊天只显示对话标题」自定义 CSS，建议删除那一段，避免关闭插件开关后旧 CSS 仍然隐藏角色名。其他自定义 CSS 请保留。

## 使用

- 默认隐藏列表额外添加的「角色名 —」。角色头像保留。
- 默认开启手机阅读优化：长标题自动换行；600px 及以下宽度时，日期和按钮另起一行。
- 在「扩展 → 对话标题」中可分别关闭隐藏和阅读优化；关闭隐藏会同时停止本插件的布局调整。
- 如果对话名称本身包含角色名，需用原有铅笔按钮手动删去。插件不会猜测或批量修改现有名称。
- 使用 SillyTavern 原有重命名功能，插件不建立另一套标题，也不改写聊天内容、角色卡、主题或安装文件。
- 原有重命名功能会修改聊天文件名。依赖旧文件名的检查点链接等行为以酒馆自身版本为准。
- 配置保存在 SillyTavern 的扩展设置中，不放入主题的 Custom CSS；扩展样式独立加载。
- 禁用/卸载整个扩展后按酒馆提示刷新页面。

## 兼容与验证

按 2026-11-20 查阅的官方 release 分支欢迎页结构开发，适用于具有 `.welcomePanel .recentChat` 列表的版本。只作用于「最近聊天」，不修改聊天窗口顶部标题。

本地浏览器测试使用官方列表结构和官方欢迎页 CSS，验证手机宽度、大字号、主题样式替换、动态列表、原按钮事件和开关恢复。尚未在用户的手机及其第三方主题上实机验证。完全改造最近聊天 DOM 的第三方主题可能需要适配。

## 隐私

扩展自身不发送网络请求，不读取或上传聊天正文。使用酒馆原有设置保存机制保存两个开关。
